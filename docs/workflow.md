# Workflow взаимодействия с вузом

University Flow CRM использует workflow из 14 этапов.

1. Поиск контакта.
2. Коммуникация и уточнение актуальности программ.
3. Организация встречи с представителями вуза.
4. Обмен необходимым пакетом документов.
5. Корректировка документов перед подписанием.
6. Подписание документов.
7. Передача обучающих материалов, лицензий и документации.
8. Сопровождение внедрения ИТ-продуктов в вузе.
9. Обучение преподавателей.
10. Актуализация учебной программы по ИТ-направлению.
11. Ведение занятий.
12. Актуализация документации и обучающих материалов.
13. Повышение квалификации преподавателей.
14. Контроль исполнения каждого этапа.

## Общие статусы

- В работе.
- Ожидает согласования.
- Договор подписан.
- Обучение преподавателей.
- Завершено.

## Реализация в MVP

Для каждого вуза сохраняются:

```text
currentStage
stageName
status
comment
updatedAt
```

Пользователь может изменить этап, добавить комментарий и сохранить изменения.
