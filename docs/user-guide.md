# Руководство пользователя

## 1. Вход в систему

Пользователь открывает веб-приложение University Flow CRM.

## 2. Работа с реестром вузов

На главной странице CrmHome пользователь видит:

- краткую статистику;
- фильтр по статусу;
- список вузов;
- кнопку добавления нового вуза;
- кнопку перехода к отчётам.

## 3. Фильтрация вузов

Пользователь выбирает статус в выпадающем списке:

- Все статусы;
- В работе;
- Ожидает согласования;
- Договор подписан;
- Обучение преподавателей;
- Завершено.

После выбора система показывает подходящие карточки вузов.

## 4. Добавление нового вуза

1. Нажать кнопку «Добавить вуз».
2. Заполнить название вуза.
3. Указать город.
4. Выбрать ИТ-направление.
5. Указать ИТ-продукт.
6. Указать номер этапа
7. Указать название этапа
8. Выбрать этап workflow.
9. Нажать «Сохранить».

Название вуза и этап workflow являются обязательными полями.

## 5. Работа с карточкой вуза

1. Открыть нужный вуз из реестра.
2. Просмотреть текущий этап, статус и комментарий.
3. Выбрать новый этап workflow.
4. Добавить комментарий.
5. Нажать «Сохранить изменения».

После сохранения статус и комментарий обновляются в реестре Firestore.

## 6. Формирование отчёта

1. Открыть раздел «Отчёты».
2. Выбрать период.
3. Выбрать статус.
4. Выбрать формат отчёта.
5. Нажать «Сформировать отчёт».

В MVP отображается демонстрационный предпросмотр отчёта.
